# ⚡ مرکز شبکه‌ها و بسترهای انتقال (Transports Hub)
### تفکیک کانفیگ‌ها بر اساس نوع لایه و استریم ارتباطی

در این بخش، تمام کانفیگ‌های تاییدشده بر اساس ۴ بستر اصلی انتقال داده دسته‌بندی شده‌اند:

| نام بستر | فایل اختصاصی | ویژگی فنی و کاربرد |
| :---: | :--- | :--- |
| 🛡️ **gRPC** | `grpc.txt` | استریم‌های موازی بستر HTTP/2؛ بالاترین مقاومت در برابر پکت‌های قطع ارتباط در ساعات اختلال شدید ملی |
| 🚀 **XHTTP** | `xhttp.txt` | جدیدترین شاهکار هسته Xray (پروتکل SplitHTTP پسا-کوانتومی)؛ ضد فریز شدن ترافیک و عبور هوشمند |
| 🌐 **WebSocket** | `ws.txt` | وب‌سوکت استاندارد و همه‌منظوره؛ دارای بالاترین سازگاری با تمام گوشی‌ها، سیستم‌عامل‌ها و کلاینت‌ها |
| ⚡ **TCP** | `tcp.txt` | اتصال مستقیم و بهینه‌سازی‌شده Reality-Vision؛ کمترین تاخیر و پینگ بسیار پایین برای وب‌گردی روان |
